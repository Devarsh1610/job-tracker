# JobTrackr — Job Application Tracker

**Author: Devarsh**

## Description

JobTrackr is a web application that helps users keep track of their job applications.

Users can create an account and log in to manage their job applications. They can add, view, edit, and delete applications while keeping track of information such as the company, job title, date applied, application status, and notes.

The application also allows users to search and manage their job applications easily.
